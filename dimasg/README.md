📄 Project Overview: Dimas George Portfolio Website
This project is a modern, static portfolio website for an individual named Dimas George. The website serves as an interactive entry point to showcase professional experience, education, side projects, and contact information. The design should feel clean, immersive, and modern, with dynamic motion effects and intuitive navigation. Users begin on a minimalistic landing page with a bold title and an “ENTER” call-to-action. Upon entering, they are greeted with a smooth animation revealing four visually rich, interactive bubbles. These bubbles lead to dedicated pages with placeholder content, each representing a section of Dimas George's professional portfolio. The background should respond to user interaction, creating an engaging and "alive" feel throughout the experience.
